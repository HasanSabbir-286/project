# ATM Machine (Python)

A simple command-line ATM Machine built using Python.

## Features

- Check account balance
- Deposit money
- Withdraw money
- Input validation
- Exit confirmation

## Concepts Used

- Functions
- while loop
- if / elif / else
- try / except
- return statements
- User input validation

## How to Run

```bash
python ATM_machine_project.py
```
